    About Smart Rental Management System

    Second-Year Computer Engineering Capstone Project

    Project Overview

    The Smart Rental Management System (SRMS) is a real-world, full-stack multi-category rental platform created to bridge theoretical Object-Oriented Programming (OOP) concepts with enterprise software architecture.

    Instead of a toy console application, this project delivers a production-style decoupled web architecture: a high-performance C++17 REST API backend running on an embedded multi-threaded HTTP server (cpp-httplib), backed permanently by MySQL 8.0 Community Server with InnoDB storage engine, and a modern frontend built with HTML5, CSS3, JavaScript ES6, and Bootstrap 5.

    Core Pillars of Engineering

    29 OOP Concepts Grounded

    From fundamental encapsulation to abstract factories, templates, operator overloading, and RAII resource guards.

    MySQL 8.0 Workbench Integration

    Full InnoDB relational schema with 13 tables, foreign keys, cascade triggers, and dedicated least-privileged user access.

    Polymorphic Business Logic

    Dynamic duration discounting, insurance calculations, check-in late fees, and audited security deposit refunds.

    4 Comprehensive Categories

    Realistic Indian rental domain models for Automobiles, Two-Wheelers, Real Estate, and Home/Office Furniture.

    Our Mission & Academic Vision

    To demonstrate that low-level systems programming in C++ can power modern web applications with unparalleled efficiency, rigorous memory safety, and strict compile-time type validation, providing students and evaluators with a blueprint for modern full-stack systems design.
